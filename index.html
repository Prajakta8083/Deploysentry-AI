About DeploySentry AI

An AI-augmented deployment gatekeeper for CI/CD pipelines.

DeploySentry AI evaluates proposed code changes against configurable risk rules before they reach production. When a change is flagged or blocked, Gemini generates a plain-English explanation so developers understand exactly why — without digging through logs.

Developer pushes code │ ▼ Jenkins triggers pipeline │ ▼ DeploySentry /evaluate is called │ ▼ Policy Engine checks rules.yaml │ ▼ Decision: APPROVE / REVIEW / BLOCK │ ▼ Gemini explains (if REVIEW/BLOCK) │ ▼ Logged to SQLite audit trail │ ▼ Exit code returned to Jenkins
